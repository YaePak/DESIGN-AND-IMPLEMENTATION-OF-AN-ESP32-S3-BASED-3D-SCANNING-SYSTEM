# Definitions and Theory

This directory contains the system specification, theoretical background, and operating algorithms of the ESP32-S3-based 3D scanning system.

## Documents

### 1. [System Specification](System_Specification.md)

Describes the system's functional requirements, technical requirements, target measurement range, target resolution, and system limitations.

### 2. [System Theory and Operating Algorithm](System_Theory_and_Operating_Algorithm.md)

Explains the operating principles of the GP2Y0A51SK0F infrared distance sensor, stepper motor control, data sampling, XYZ coordinate conversion, and the system operating flowchart.

## Purpose

These documents provide the technical foundation for understanding the system design and scanning process before implementation and testing.
