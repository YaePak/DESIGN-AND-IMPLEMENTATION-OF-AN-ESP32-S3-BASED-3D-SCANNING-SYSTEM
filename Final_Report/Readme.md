# Final Report

This directory contains the final report and presentation for the ESP32-S3-based 3D Scanning System project.

## Files

| File | Description |
|---|---|
| `Final_Report.docx` | Editable Microsoft Word version of the final report. |
| `Final_Report.pdf` | PDF version of the final report for viewing and distribution. |
| `Final_Presentation.pptx` | PowerPoint slides summarizing the project, system design, implementation, and results. |

## Contents

The report and presentation cover the project overview, system architecture, hardware and software design, implementation, testing results, limitations, and future improvements.
