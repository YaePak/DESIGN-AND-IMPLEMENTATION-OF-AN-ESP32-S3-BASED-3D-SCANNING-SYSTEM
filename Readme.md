# 3D Scanner

## Project Overview

This project focuses on the design and development of a homemade 3D scanner using embedded hardware, distance sensors, motor control systems, and mechanical components.

The main objective is to build a low-cost scanning system capable of collecting distance information from a physical object and converting the collected measurements into three-dimensional data.

The scanner is designed to measure an object from multiple positions while controlling its mechanical movement. The collected measurements can later be processed into a point cloud and used for three-dimensional model reconstruction.

The project is inspired by existing homemade 3D scanner concepts but will be redesigned and developed based on our own hardware, software, mechanical structure, and system architecture.

---

## Why We Chose This Project

We chose the 3D Scanner project because 3D scanning is an interesting technology with practical applications in many fields, including manufacturing, reverse engineering, product design, digital modeling, and object measurement.

Commercial 3D scanners are often expensive and may require complex hardware and specialized software. Therefore, we wanted to explore whether a simpler and lower-cost system could be designed using commonly available components and embedded technology.

Another reason for choosing this project is the engineering challenge of achieving reliable results with limited hardware resources. The performance of the scanner depends not only on the distance sensor, but also on mechanical accuracy, motor positioning, measurement validation, and data processing.

Therefore, this project is not simply about building a scanner. It also provides an opportunity to investigate how hardware limitations, sensor accuracy, mechanical design, and software algorithms affect the quality of the final 3D model.

Our goal is to design and develop a functional prototype while understanding how different engineering components can work together to solve a real-world problem.
